    GAP Register — the single source of truth for open gaps¶

    Status: living document. This register is the only place where the project's current gap state is tracked. The dated audit reports listed in the Snapshots ledger remain frozen as historical evidence — they are never refreshed (doc-update-audit-20261029 L5 convention) and their findings are inherited here, deduplicated and re-adjudicated.

    When any audit, plan, or issue identifies a gap, add or update a row here instead of writing a new report. Close rows with evidence (commit, scenario, command output), not with optimism.

    Row schema¶

    Field Meaning
    ID Stable identifier; never renumber, retire instead
    首见 (origin) Earliest snapshot/issue that recorded the gap
    状态 open · mitigated（登记能力债/显式降级，属合规状态） · dormant（裁决休眠，有恢复条件） · resolved（附证据） · wont-fix（裁决不做）
    证据 Commit / file:line / scenario / command that proves the current state

    Numbers are never stored here. LOC, test counts, scenario counts and the like drift; the derived truth lives in scripts/check-doc-consistency.py.
