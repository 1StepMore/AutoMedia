# promo/ — video-engine quality baseline kit

Imported verbatim from `hyperframes-remotion-kit-20261103.zip` (owner-provided
HyperFrames + Remotion reference implementation). This is the quality baseline
for the video-engine work tracked in issue **#351** — see the gap register
(`docs/dev/gap-register.md`, GAP-PROD-1) and the kit's own
`00-README.md` / `docs/给Agent的使用说明.md` for how to consume it.

What each part is for:

- `docs/` — methodology: two-line selection (HyperFrames vs Remotion),
  narration-segment timeline alignment, motion-grammar prohibitions, Azure
  TTS notes. Read these before touching `engines/implementations/video_*`.
- `hyperframes/` — deterministic HTML/JS line (`render(t)` + puppeteer
  per-frame render) — the reference for the light-track hyperframes engine.
- `remotion/` — React/Remotion line (`DemoFilm18.tsx` + a 2.4k-line motion
  kit) — the reference for the future remotion-track engine.
- `reference/` — target outputs ("what qualifies as good").

**In-repo difference vs the original zip:** the two `reference/*.mp4` files
(≈19 MB) are excluded from git for size. `02-verify.py` will therefore report
exactly those two entries as missing — that is expected here, not corruption.
Everything else is byte-identical to the zip (manifest md5s hold for the 35
present files; the excluded mp4s can be regenerated by re-rendering either
line per the kit READMEs).

This directory is reference material — it is **not** packaged into the wheel
and not imported by `src/automedia/`.
