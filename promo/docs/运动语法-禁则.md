# 运动语法与禁则（Remotion 线务必遵守）

本仓 Remotion 片的「高级感」来自一套固定语法。**违反禁则 → 出片会显得廉价**。

## 令牌（theme）
- 唯一强调色 = 钴蓝（`#1F2BE0` / 提亮 `#5D6DFF`）；底 `#08090D`；纸色 `#F0EBDE`。
- 字体：标题 Noto Serif SC，正文 Noto Sans SC。
- 动效 tokens：入场 `cubic-bezier(0,0,0.2,1)`、出场 `power2.in` 感、单次动作 ~21 帧、接缝 18 帧。

## 语法（本 demo 用了这些）
- **速度匹配横移接缝**：入场已带位移（不从静止开始）、出场在运动中切走。
- **镜头推近**：每场 `scale 1.00→1.04`（inOut cubic），不来回。
- **压印字效**：文字入场 = 缩放 1.16→1 + 模糊 4→0 + 字距收拢。
- **发丝网格**：12 栏竖向 hairline 打底。
- **SVG 湍流颗粒**：`feTurbulence` 全屏 soft-light，确定性。
- **spring 入场**：标题/元素用 spring（damping ~14）而非线性淡入。

## 禁则（违反即重做）
1. 禁 idle wobble —— 呼吸/漂浮/光脉冲当持续运动。
2. 禁 crossfade —— 没有载体，眼睛抓不住。
3. 禁静止后切 —— 必须两侧都在运动中途切。
4. 禁从静止入场 —— 入场要 ≥50% 已进入航程。
5. 禁连续反向接缝（乒乓）。
6. 禁跨轴切换（x→y）。
7. 禁 bounce.out / elastic.out 缓动。
