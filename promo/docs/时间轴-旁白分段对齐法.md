# 时间轴：旁白分段对齐法（两线共用）

**问题**：场景切换凭感觉 → 音画不同步。
**方法**：
1. 把旁白按**场景**切成 N 段，每段单独 TTS 合成（Azure），`ffprobe` 量出每段真实时长。
2. 累加得每段起止秒 → 这就是场景时间轴（画面切点 = 旁白句号）。
3. 把 N 段音频按顺序拼接成 `narration_full.mp3`（总长 = 各段之和）。
4. 视频 `DUR` = 总长；每场帧数 = 该段时长 × fps（如 30）。
5. 渲染时**按秒 seek**（hyperframes `window.__seek(t)` / remotion 按 frame 计算），保证第 i 秒画面 = 第 i 秒旁白。

**本 demo 实测**：6 段 → 0–7.82 / 7.82–17.54 / 17.54–28.92 / 28.92–34.68 / 34.68–44.28 / 44.28–52.22（秒），总 52.22s，对应帧数 235/292/341/173/288/238（合计 1567 @30fps）。

**坑**：
- 别用 12fps 渲染再 `-r 30` 提帧（= 重复帧顿挫）。直接按目标帧率渲染。
- 旁白改了就重算时间轴，别只改音频不改切点。
