# 两条线怎么选

| | HyperFrames 线 | Remotion 线 |
|:--|:--|:--|
| 技术 | 纯 HTML + 确定性 `render(t)` + puppeteer 逐帧 + ffmpeg | React + Remotion 4 |
| 依赖 | 浏览器 + puppeteer-core + ffmpeg | Node 18+ + remotion（自带 chrome） |
| 机器要求 | 低（浏览器能开即可） | 中（要跑 webpack/react） |
| 改内容 | 改 HTML/CSS | 改 TSX 组件 |
| 动效上限 | 中（手写 JS 动画） | 高（组件化、可接 three.js/转场库） |
| 适合 | 快速出片、机器受限、模板化批量 | 品牌级高质量、复杂 motion、长期迭代 |
| 本包产出 | demo-hyperframes.mp4（3MB） | demo-remotion.mp4（16MB，首选） |

**结论**：demo/展示用 Remotion 线；受限环境或需要确定性批量时用 HyperFrames 线。两条共用同一套「时间轴 = 旁白分段时长」方法（`时间轴-旁白分段对齐法.md`）。
